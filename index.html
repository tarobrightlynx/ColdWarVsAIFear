Key interpretation

The paper’s central finding is not that technological fear disappeared. Instead, fear changed form. Cold War fear asked whether technology would destroy civilization. AI fear asks whether technology will replace, monitor, mislead, govern, or make decisions for humans.

Category profile across the three periods

Category scores range from 0 to 1. Because one document can contain multiple fears, category percentages do not need to add to 100%.

Method and automation summary

The static website is updated by a scheduled GitHub Actions workflow, not by JavaScript running in the browser.

Monthly workflow

  • 1. Discover and scrape current AI articlesThe workflow runs scrape_ai_articles.py with recent discovery for the last four weeks.
  • 2. Categorize fearThe workflow runs categorize_scraped_texts.py, which produces an overall CSV with the mean Likert score and category proportions.
  • 3. Update the dashboardupdate_dashboard_from_results.py reads the CSV and rewrites the latest AI values embedded in this index.html.

Limits to keep in mind

The latest monthly scores depend on which articles are discoverable and successfully scraped. Paywalls, blocked pages, source selection, and model interpretation can affect the results. For paper-level consistency, increase the workflow’s coding runs to 25.
